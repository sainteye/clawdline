# Opportunity cost

Use this skill when choosing what to do next with scarce time, people, or money, such as ordering a backlog, accepting a large commitment, or weighing new work against debt. Every commitment displaces its best alternative.

1. State the choice, the resource it consumes (for example engineer-days), and the decision horizon.
2. List the real alternatives for the same resource: the proposal, the next-best productive use, and doing nothing or waiting. Drop options with no owner or no feasible path.
3. Estimate each path's value, risk, and time to value in comparable rough magnitudes, citing where each estimate comes from. Do not manufacture precision.
4. Name the best forgone alternative and the difference between the chosen path and it. Decide on that difference, not on the chosen path's value alone.
5. Mark which losses are temporary and which are permanent (a window that closes, a lock-in).
6. Argue the strongest case that the ranking is wrong, recompute, then decide: proceed, switch, wait, or split.

Skip the analysis for mandatory work (a security fix, a hard dependency) and for trivial or cheaply reversible choices. Ignore sunk cost. The decision belongs to whoever owns the plan; present it as a recommendation with its trade-off.
