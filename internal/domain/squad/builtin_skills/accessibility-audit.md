# Accessibility audit

Use this skill to review an interface for perceivable, operable, understandable, and robust behavior. Define the page states, devices, and assistive technology actually available for this audit.

1. Inspect semantic structure, labels, alternative text, contrast, text enlargement, and error messages. Verify every finding against the rendered interface.
2. Navigate with keyboard only: focus entry, order, activation, escape, dialog return, and recovery after updates. Test reduced motion when animation is present.
3. Use an automated checker to find candidates, then manually confirm them. Where possible, inspect the accessibility tree and test with a screen reader.
4. Report each issue with a reproducible path, observed behavior, expected behavior, severity, and the limits of the test environment. Retest fixes.

Do not claim legal compliance or substitute this audit for testing with disabled users.
