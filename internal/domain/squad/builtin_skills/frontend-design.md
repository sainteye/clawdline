# Intentional interface design

Use this skill when shaping a new screen or substantially improving an existing interface. Begin with the product purpose, content hierarchy, and the repository's current visual language.

1. Define the key user action and a clear visual direction. Sketch layout, type hierarchy, spacing, color, and states before polishing details.
2. Make components feel related while giving the most important action and information visible priority. Avoid decorative treatment that hides status or meaning.
3. Review actual rendered desktop and mobile layouts, long copy, enlarged text, keyboard focus, and reduced motion. Adjust from screenshots and interaction evidence.
4. Explain design choices in terms of user task and product constraints. Keep the implementation accessible and maintainable.

Do not replace the current product's design system with generic examples from an upstream skill.
