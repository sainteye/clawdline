# Bot 工作卡：給你看的摘要

狀態：提案，等你審閱。還沒有實作任何東西。完整設計（英文）在
[`bot-work-cards.md`](bot-work-cards.md)。

## 要解決什麼

你把工作交給幾位常駐 Bot：開發、審查、測試，最後由整合的 Bot 合併、推上 GitHub、裝到這台
電腦的開發版，再部署到 Cloud。這個月下來，進度全寫在聊天裡，出了幾件事：

- 想知道「這個功能現在到哪了、上線了沒」，得翻好幾個 Bot 的對話。
- 審查 Bot 退回了兩個 commit，它們還是上了 GitHub 和 Cloud。退回只是一句話，本機為了退回而做的
  還原又在一次重設時不見了，沒有任何東西擋住推送和部署。
- 「這個 commit 取代那個」「這次合併順便帶上那個」這類關係，只存在對話裡。
- 每次都要有人手動比對本機、GitHub、開發版、Cloud 的版本，上線後通知原本交辦的 Bot 也是靠記得。

## 它是什麼

一張「Bot 工作卡」對應你交代的一件事。卡片是獨立的一類紀錄：不是看板項目，不算進看板的數字，
你自己建的看板項目和 Session 的用法都不變。

卡片記錄：

- **是誰授權的**：你哪一則訊息（或 Bot 轉達你的哪一則訊息）。
- **現在在誰手上**：開發、審查或整合，以及是哪一位 Bot。交接都留紀錄，不能改寫。
- **審查結果**：通過、有條件通過（寫明條件）、退回，每一個都綁定確切的 commit。
- **四個去處的實際狀態**：本機 main、GitHub、這台電腦的開發版、Cloud。每一項都由系統自己去讀，
  附上讀到的版本和時間，不採信 Bot 的說法。讀不到就顯示「不明」，不會被當成完成。

## 你會看到什麼

- **看板多一區「Bot 工作」**，可以依 Bot 篩選。每張卡有六個燈：建置、審查、main、GitHub、
  開發版、Cloud。綠燈代表已驗證，滑過去看得到版本和時間；灰色代表這張卡不需要；黃色是還在等；
  紅色是被擋下或被退回；問號是讀不到，並寫出原因。
- **需要你的卡放在這一區最上面**：Bot 在等你回答，或系統發現被退回的東西已經上線了。
- **Bot 聊天室上方那條派工列**，會把同一張卡的工作排在一起，一行就看得到燈號。
- **手機和 Cloud 看到同一份資料**，內容一樣經過加密傳送。

## 它會替你擋什麼

被退回、而且之後沒有被取代的 commit，**推上 GitHub、裝開發版、部署 Cloud 時都會被擋下**，
並說明是哪張卡、誰退回的。系統查不清楚時也會擋。合併到本機 main 不擋（還能收回），但燈號會
變紅並告訴整合的 Bot。

只有你能放行被退回的 commit，要寫理由。Bot 沒有任何方式自己放行。

老實說一個限制：推送前的檢查可以被刻意跳過。所以系統另外會持續核對 GitHub 和 Cloud，
一旦發現被退回的東西已經上去，就把卡片標成「需要你」並通知你。

## 什麼時候算完成

這張卡需要的去處全部驗證過，系統就自己把它標成完成，並通知當初交辦的 Bot（只通知一次，
重開機也不會重複）。哪些去處是必要的，可以每張卡不同，例如只改文件的卡不必上 Cloud。
Bot 不能自己宣布完成；你可以手動完成或取消。

## 卡片從哪裡來

你交代 Bot 一件**會改到程式或文件**的事，Bot 第一次派出要寫檔的工作時，系統就自動開卡。
只是問問題、做調查不會開卡。同一則訊息不管經過幾位 Bot、重試幾次，都只會有一張卡。

## 刻意不做的

- 不幫你排誰來審查，也不替 Bot 跑建置、推送或部署。
- 不處理從別台電腦的 Bot 網路送來的請求。
- 不涵蓋公開版發布與官網。
- 不改動看板項目，也不放進看板的數字。

## 需要你決定的事

1. 看板的「Bot 工作」區要**預設顯示**，還是像「Agent 提案」一樣**預設隱藏**、勾選才顯示？
2. 需要你處理的 Bot 工作卡，要不要也出現在看板的「需要處理」欄？（會讓兩種紀錄在那一欄混在一起；
   不放的話，只在 Bot 工作區、Bot 聊天室和通知裡出現。）
3. 一則訊息裡交代了好幾件不相干的事，開一張卡就好，還是讓 Bot 拆成幾張？
4. 新卡預設要求哪些去處：四個都要，還是本機 main 和 GitHub 必要、開發版和 Cloud 由開卡的 Bot
   依內容決定？
5. 推送前的檢查可以被刻意跳過，搭配「發現已上線就警告」夠不夠？還是要求所有推送都改走
   Clawdline 的指令（改動比較大，Bot 的習慣也要跟著改）？
6. 被退回的修改如果被複製成新的 commit，要不要也認得出來？（推送前的檢查會稍微慢一點。）
7. 卡片完成時，只通知交辦的 Bot，還是也通知你？
8. 「有條件通過」要不要也擋推送和部署，直到整合的 Bot 說明條件已經達成？還是只顯示出來？
