# Frozen native checker-text pilot
Six Codex review children, three historical candidates, one control/treatment pair per candidate. No reruns or automatic replacements. All use the native Clawdline task lifecycle, Code Reviewer role, gpt-6.1-sol, and the machine's fixed Codex effort setting; record the actual role snapshot and configuration. Existing ChatGPT subscription only, no usage-priced API call or API-key fallback is authorized.
Each run has its own shallow clone of candidate plus parent. Read-only source review, no tests, network, writes, delegation or runtime claims. Same role and claim per pair. Treatment is extracted from the actual writeGateCheckerBrief output (Frozen candidate through Acceptance and required checks). Control removes ONLY the new Review scope and integration completeness section. Evidence upload/closed-verdict instructions are intentionally excluded: these are historical review children, not live verification-gate rounds. Go behavior tests separately check the real checker pinning and closed verdict.
Fixed order cloud control/treatment, background treatment/control, docs control/treatment; at most four in flight. Score only after all results, without prompt adjustment. Root scoring is not independent or statistically powered. G1 cloudops snippets unknown_command (1); background watchWaiting answer-needed push loss (1), dead sweep health/listing clock (1); docs obsolete read-only/open --send guidance (1), seven stale locales (1). Same mechanism with incomplete consequence receives 0.5. Record true extras, intent questions, runtime gaps and other findings separately. Max score5 per arm. No clean control in this six-run pilot; false-positive rate cannot be established. Do not pool with the earlier role-text pilot or Claude runs.

## Observed deviations, retained rather than repaired after the fact

The machine changed from dev 928bedd to dev e332bf5 while launches were in progress. Five samples loaded role version 1d280ec7; the documentation treatment loaded 63242910. That pair is confounded. Code Reviewer skill loading also varied: some workers read/applied the two-axis skill outside the narrow clone/role-file allowance, while others declined it. Two workers used head to truncate shell output despite the git/rg/sed allowlist. These are protocol deviations, not grounds for silently replacing samples. The machine's ChatGPT authentication mode and all six actual transcript model/effort records were checked; requested flags alone were not used as model proof.

The scorer read opaque report copies, but two reports label their prompt arm and treatment instructions are recognizable. Blinding was therefore incomplete; the same Root scored and implemented the feature. No causal improvement, equivalence or false-positive-rate conclusion is supported.
