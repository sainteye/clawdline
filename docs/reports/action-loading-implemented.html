驗證方式與範圍

核准的 18 個代表畫面使用本輪 Chrome、產品元件與樣式擷取。圖片以明示的合成資料固定等待狀態；手機 390px、430px 與桌機 1024px 的操作按鈕未溢出。每個畫面都有 14px 旋轉圖示，並通過減少動態效果檢查。

另以完整 Console 與本機合成 daemon 延遲常用流程儲存，檢查重複點擊只送出一次；模擬失敗後等待提示消失、保留錯誤，再重試成功並完成刪除。這項驗證不代表已實測每組操作的所有分支，也未量正式環境延遲或驗 iOS/WebKit。

所有請求均停留在測試環境；沒有對正式帳號送出操作。正式 Cloud 上線狀態以交付回覆為準。
