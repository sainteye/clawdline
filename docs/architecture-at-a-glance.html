Clawdline 架構，
一眼看懂。

工作在自己的機器上執行。Cloud 管帳號與路由。瀏覽器讓人看見、操作與回應。

一個 Go daemon一套 React console，兩種建置Cloud 選用，預設關閉內容端對端加密
全貌資料庫瀏覽器路徑記憶位置功能比例信任邊界指令生命週期開發入口
01

三個位置，一條主線

本機瀏覽器直連 daemon；Cloud 瀏覽器透過服務找到目標機器。兩條路最後都回到那台機器處理資料與執行動作。

02

「DB」其實有三個

各自回答不同問題：本機的工作事實、Cloud 的帳號事實、relay 的路由與計量狀態。

關聯式資料庫 · 本機檔
Cloud control plane

MongoDB

帳號、機器與瀏覽器裝置、權限、訂閱、用量、Push 訂閱、webhook 設定與送達中繼資料。

文件集合 · Cloud
Cloud data plane

Durable Object

每帳號一個 SQLite-backed object；持久保留裝置撤銷、通道與計量狀態。最新密文快照只放記憶體。

持久 key/value ＋ 記憶體快取
Session 逐字稿、專案檔案和終端機內容沒有集中搬進 Cloud DB。Claude／Codex 的原始逐字稿由它們自己寫在本機，Clawdline 讀取。

04

誰記得什麼？

儲存形式比「是不是 JSON」更重要：資料的主人、壽命與可讀者不同。

Cloud 持久
MongoDB 文件 ＋ Durable Object metadata：帳號、裝置、權限、訂閱、計量、通知與 webhook 收據。
Cloud 暫時
傳輸中的加密 JSON 信封；relay 記憶體中的最新加密快照。快取會隨 object 休眠消失。
機器持久
SQLite 工作事實；task.json、result.json、設定、金鑰、Markdown 文件與圖片檔。逐字稿由 Claude／Codex 寫入本機。
瀏覽器持久
IndexedDB 裡的配對與加密金鑰；少量偏好／暫態紀錄在 localStorage、sessionStorage。
JSON 是 API 與加密信封的格式，也是若干本機檔格式；它不是全系統唯一的資料庫。Cloud 可見路由識別與用量等 metadata，看不到加密信封內的工作文字。
