頂列的 Session 狀態篩選

頂列計數那一格不再打開機器負載，而是打開「顯示哪些 Session」的篩選視窗；清單上方「重新整理／需要注意／工作中／靜置」那一整列收進視窗裡。以下三個方向都可以直接點：按頂列計數打開，按選項、套用、取消或點背景關閉。裡面的 Session 名稱都是示意。

範圍

A　計數即篩選鈕，勾選後套用

建議

頂列照舊說「幾個在跑、幾個在等你」，只是整格變成看得出能按的鈕。視窗是勾選清單，可複選；按「顯示 N 個」才生效，取消或點背景不改變目前的篩選。重新整理變成搜尋框旁的圖示鈕。

  • 複選：勾幾項就顯示幾項的聯集；不勾任何一項等於全部顯示
  • 套用：按鈕直接寫出結果數量，0 個時也照樣能套用
  • 篩選中：頂列換成已選的狀態名稱，加橘色框
  • 重新整理：搜尋框右側 44px 圖示鈕，不佔整列

B　按了就生效的狀態磚，重新整理在視窗頂端

計數文字保留成安靜的資訊，旁邊多一顆漏斗鈕，選了幾項就掛幾的徽章。視窗從頂列往下展開，四塊大磚按一下就立刻篩選，清單在背後跟著變；沒有「套用」，「完成」與點背景都只是收起來。重新整理和「多久前更新」放在視窗最上面，跟狀態數字在一起。

  • 複選：磚可以同時按亮多塊，結果是聯集
  • 套用：即時，沒有取消；要回去就按「全部顯示」
  • 篩選中：漏斗鈕變橘並顯示已選項目數
  • 重新整理：視窗第一列，附上次更新時間

C　單選的檢視切換，等同現在的行為

頂列直接寫出目前的檢視名稱，像下拉選單。一次只能看一種狀態，點一下就切換並關閉，跟現在清單上那排按鈕的單選行為完全一樣，實作風險最低。代價是不能同時看「需要注意」和「工作中」。重新整理在選單底部，手機上也可以在清單頂端往下拉。

  • 單選：全部、需要注意、工作中、靜置，四選一
  • 套用：點選即切換並關閉
  • 篩選中：頂列的檢視名稱變橘
  • 重新整理：選單底部一顆鈕，加上下拉更新

等你決定的事

  1. 採用哪個方向，或混搭（例如 A 的勾選＋套用，配 B 把重新整理放進視窗）。
  2. 要不要複選。建議複選、取聯集，「全部顯示」等於清空勾選。
  3. 是否加入第四個「狀態未更新」選項，讓勾滿四項真的等於全部。現在的篩選裡，這類 Session 只在「全部」看得到。
  4. 單台機器的檢視要不要也加上相同的篩選。目前單台清單只有文字搜尋，需要先定義「需要注意」在單台資料上怎麼判斷。
  5. 篩選要不要記住：重新開頁後保留，或每次回到全部。
