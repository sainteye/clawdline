# 檢查與回報問題

開啟「設定 → 狀態 → Doctor → 開始檢查」。Doctor 會顯示正在執行的 Clawdline
版本、Claude Code 與 Codex CLI 版本、額度讀值，以及近期已記錄的失敗原因。
檢查不會傳送模型訊息，也不會收集登入 Token。

展開「預覽完整報告」可核對所有收集欄位。需要保留或改用另一部裝置回報時，
可以下載 JSON 報告。在 Cloud 可選填問題描述、附上截圖並閱讀私人提交同意說明，再按
「提交私人回報」。送出後可從回報連結查看回覆。描述中請勿包含密碼、API Key
或私人對話。

若出問題的機器暫時無法連線，可登入 [Doctor 報告上傳頁](https://app.clawdline.com/help/doctor)，
選取先前下載的 Doctor 報告。載入檔案不會立即上傳，仍須由你明確同意並提交。
報告與描述會保存在 Cloud，提供你、Clawdline 支援人員及回答 Agent 閱讀，
不會成為公開社群貼文。

若提交結果尚未確認，請按「重新確認同一筆回報」。重新載入頁面後也會沿用
原始報告與請求編號，不會另外建立一筆。請使用原本提交時的帳號。

只有終端機的機器可執行 `clawdline doctor --json`，從正在執行的服務程式取得
同一份報告，並將輸出另存為 JSON 檔供稍後上傳。原本不帶參數的
`clawdline doctor` 仍保留基本安裝檢查。

沒有額度資料代表未知，不代表用量為零。Claude 額度依賴 status line 快取；
Doctor 不檢查其登入憑證，也沒有觀察上游 usage 請求。近期歷史僅涵蓋
Clawdline 實際讀取額度的時間，最多保留三天、24 次變化，並明確列出缺漏。
報告能協助定位失敗環節，但不一定足以證明原始原因。
