# 看板派發時選擇模型

看板 ticket 的派發入口與一般「新增 Session」不同。在看板卡片的「啟動新 Session」區選擇 Claude 或 Codex，展開「模型」，選擇這張 ticket 要使用的模型，最後按「啟動新的 … Session」確認。

模型選項預設收合，摘要會顯示目前選擇；保留預設時沿用該機器的助理預設模型。這是單次派發的選擇，不會修改整台機器的預設值。切換助理不會把另一個助理的模型選擇帶過去。

選模型本身不會啟動工作。如果有角色目錄，另可在「角色」區請 AI 推薦角色，仍要按最後的啟動按鈕才會派發。角色推薦與模型選擇是不同操作；目前這個看板流程沒有自動推薦模型的控制項。
