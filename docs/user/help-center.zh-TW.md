# 提問與查看回覆

在 [Cloud 問答中心](https://app.clawdline.com/help) 查找常見問題，或向 Clawdline 支援團隊提出產品操作問題。提出問題與查看自己的問答紀錄需要登入。問答中心是會員服務；即使配對的機器不在線上，仍可開啟已保存的問答紀錄。

## 找到之前提出的問題

在 Cloud 的側邊欄「管理」選擇「我的提問」，再點選要查看的問題；手機先開啟側邊欄。也可從問答中心選擇「我的提問」，或直接開啟 [我的提問](https://app.clawdline.com/help/questions)。這裡會列出目前登入帳號提出的問題；重新整理或關閉瀏覽器不會刪除已送出的提問。

訊息依新到舊排列，最近一則支援回覆會標示「最新回覆」，並以頭像區分提問者、Agent 與支援人員。回覆會出現在同一個問題頁，由「Clawdline 支援 Agent」或支援人員署名。列表與問題頁也會顯示處理狀態。「已收到」、「回答中」或「需要支援人員協助」都不代表已經有一般答案。如果找不到之前的提問，請先確認目前登入的是當時提出問題的帳號。

## 提出問題或繼續追問

按「提出問題」，描述遇到的情況並選擇分類，不用另外填標題。可附上或貼上最多五張 JPG、PNG 或 WebP 截圖；請勿包含密碼、API Key 或私人 Session 對話。送出後，從「我的提問」回到同一個問題查看進度與回覆。回覆語言跟隨介面語言，變更語言不會翻譯舊訊息。

如果需要補充資料，在訊息下方的「繼續追問」填入內容或附圖，再按「送出追問」。問題解決後，按「標示已解決」；保存成功後會顯示綠色勾選與「已解決」。之後送出追問仍可重新開啟對話。

你的問題與回覆不會公開，僅供你、Clawdline 支援團隊與受限回答 Agent 查看。具有通用價值的內容會另外匿名整理並審核，才可能成為公開常見問題；原本的私人對話不會直接公開。

## 需要支援人員接手時

回答 Agent 依核准、固定版本的官方公開文件與產品原始碼作答。資料不足時，可能要求補充；查證後仍不足以支持答案，或涉及帳號、帳務、安全與無法確認的行為時，會轉交支援人員。「需要支援人員協助」代表正在等待人工接手，不代表 AI 已回覆。請在原本的問題補充非機密資料，不要提供憑證。

## Admin 收件區與新提問通知

只有 Admin 能開啟獨立的 [Admin 提問收件匣](https://app.clawdline.com/help/admin)。管理員可查看會員提問，並在問題詳情看到提問者名稱與固定會員 ID。這些提問者資訊不會顯示給其他會員，也不會放進推播通知。

要收到新提問通知，Admin 需在每一台接收裝置啟用一次。iPhone 或 iPad 請先將網站加入主畫面，再由主畫面圖示開啟。啟用「新提問通知」、允許瀏覽器通知權限後，可按「傳送測試通知」確認。新提問通知只顯示通用提示；點擊後會開啟該題的 Admin 問題頁，仍需通過登入與 Admin 權限檢查，不會開啟會員的私人 Session。

## 使用問題、回報問題與功能建議

送出前可選擇「提問類型」：使用問題、回報問題或功能建議；問題分類仍用來區分產品範圍。功能建議會留下需求紀錄；收到回覆不代表功能已實作。Admin 可在詳細頁修正提問類型。看板派發時如何選模型，請見[模型選擇說明](model-assignment.zh-TW.md)。
