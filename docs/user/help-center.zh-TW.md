# 社群討論

從[社群討論](https://app.clawdline.com/community/questions)詢問操作方式、回報問題或提出功能想法。所有人都能閱讀公開討論；登入後即可發文、附圖及回覆。內容、回覆、公開名稱、頭像與圖片都會公開，請勿包含密碼、金鑰或私人 Session 對話。

## 選擇適合的分類

- **使用問答**：不知道如何操作、如何設定，或想確認目前支援什麼。
- **Issues · 問題回報**：已有的功能沒有按預期運作。請描述實際行為、預期結果，並盡可能補充最短重現步驟。
- **Ideas · 功能提案**：希望增加能力或改善操作方式。先說明需求及使用情境，不用先準備實作方案。

各分類都有獨立列表與發文入口，表單會依類型調整。不必另外填標題，系統會從內容產生簡短標題。可附上或貼上最多五張 JPG、PNG 或 WebP 截圖，送出前請確認沒有機密內容。

討論列表與新 Agent 回覆跟隨既有介面語言；舊訊息不會自動翻譯，也不用另外選語言。

## 查看與參與討論

在 Cloud 側邊欄選擇「我的討論」，可以找到自己發起或參與的內容；社群導覽也有相同入口。列表會顯示作者、頭像、最近動態、回覆數與該分類的進度。建立新討論前，可先搜尋或篩選既有內容。

原始發文保留作為上下文，回覆依新到舊排列，最近一則標示「最新回覆」。會員使用公開名稱及已驗證的 GitHub 頭像；沒有頭像或載入失敗時顯示本地備援圖示。Agent 使用 Clawdline 標誌與 AI 標籤；官方支援人員使用獨立的人物插畫與團隊標籤，會員不能透過留言冒充官方身分。

登入會員都能回覆；使用問答只有原作者或 Admin 能標示已解決。一般留言不會另外啟動 Agent 工作；需要查證時，可勾選「請 Agent 查證並回覆這則內容」。Agent 只使用核准且固定版本的公開文件與原始碼；討論內容不構成執行程式、修改檔案或擴張權限的授權。

## 回覆與交付分開追蹤

Issues 分開追蹤確認、處理與發布；「待發布」代表還沒完成交付。Ideas 則追蹤討論、採納、規劃、開發與推出。收到回覆或 Agent 提案，不代表功能已被承諾或完成。

進度由 Admin 更新。確認已發布後，會記錄版本與官方發布連結，並在原討論新增一則支援人員回覆。只更新 Cloud 的功能可使用驗收過的正式 Cloud commit，不必另外發布桌面 App。服務端檢查格式及管理權限，不會自行證明部署已完成。

Admin 審核與內部回答服務設定維持獨立。Agent 可以查證問題與提出建議；實作仍依專案正常的人工審核、工作安排、檢查及發布流程進行，不會因為有人發文就自動修改或部署產品。

## 舊的支援提問

舊提問不會自動公開。作者同意後，Admin 才能明確發布指定對話與圖片。公開頁只呈現內容與公開身分，不包含會員 ID、Email、Webhook 紀錄或工作憑證。已發布的舊連結會導向公開討論；社群發文介面不提供私人支援提問選項。診斷資料可透過獨立的 [Doctor 檢查與回報](doctor.zh-TW.md) 私下提交，不會自動公開。
