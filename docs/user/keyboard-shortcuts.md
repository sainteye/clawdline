# Keyboard shortcuts

After this page you can move through the session list and a transcript without the mouse. Press
`?` in the console to see the same list (the card is titled **鍵盤**, keyboard).

Shortcuts stand down while you are typing in a text box: anything you type there stays there.

| Key | Does |
| --- | --- |
| ↑ / ↓ or `j` / `k` | Move through the session list |
| Return | Open the selected session |
| `/` | Filter the list |
| Esc | Clear the filter, then step back: close the open sheet or menu, leave a page other than the session list, or close the open session |
| ⌘K / Ctrl-K | Put the cursor back on the session list |
| ⌘J | Show or hide the transcript. On a phone it switches between the list and the session |
| ⌘I | Session info |
| `g` / `G` | Top or bottom of the transcript |
| `r` | Reverse the transcript's order |
| `?` | Show this card |

## In the message box

| Key | Does |
| --- | --- |
| Return | Send (on a touch screen, a new line; send with the button) |
| Shift-Return | New line |
| `/` as the whole message (`$` for Codex) | List the session's skills and commands. ↑ ↓ move, Tab or Return choose, Esc closes. Choosing one never sends |

## In menus and sheets

- On the **⋯** button, ↓ opens the menu; Home, End, ↑ and ↓ move; ← or Esc leaves the Git
  submenu.
- Esc closes the snippets, start, to-do and picture-marking sheets and confirmation dialogs.

## The macOS app

The native app adds a global hotkey that opens its input bar: ⌥Space by default, and by default only
while iTerm2 or the app itself is in front. Both are set in the app's settings window
([platforms.md](platforms.md)).
