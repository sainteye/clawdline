# Clawdline v2.15.0

This release lets a role carry several reviewed Skills and shows, on Session screens, when a role consults and applies one. It also regroups the tool library, adds long-conversation handoff, and improves Gemini recovery and Project setup. It contains the application changes in the previously tested dev build `a709efeaea62a7d76adbeb53cf7131ee72d81a50`.

## Role Skills

- **A role can carry up to four default Skills.** Built-in roles now reference Skills by ID, so one Skill can serve several roles and one role can list several, in order. Twenty reviewed upstream Skills were adapted and bundled: 33 of the 44 built-in roles now carry defaults drawn from 46 built-in Skills. Each adaptation is pinned to a commit with its licence notice and reference audit in the [decisions record](../persona-skill-decisions.md). Earlier role versions, Project overrides and Session snapshots keep resolving.
- **See Skill use while it happens.** When a role reports reading a Skill, a strip of that role's Skills appears under the Session header and the Skill is marked as being consulted; when it reports applying it, the role's bot hops and a green check appears. The Session transcript records each Skill at the point it was used, and a finished task shows which Skills were used and which were not. Tapping a Skill, or the role's bot, lists every Skill with what it is for and this Session's state. Reloading shows the state without replaying motion; the Squad motion setting and reduced motion are respected.
- **Skill use on the phone's multi-machine screens.** The all-machines Session list and a pinned machine's conversation show the same Skill use, with one event feed per machine.
- **Cheap to load.** Session screens read Skill receipts and launch snapshots only for the Sessions on screen, in batches, instead of the whole receipt log. A machine without the new filters falls back without repeated full reads.
- A controlled trial (one role, four Skills, 16 runs) found roles opened 15 of 16 needed Skills and skipped 39 of 40 unneeded ones. It had no no-Skill control group, so it shows the listing is selective, not that Skills improve results.

## Tool library

- **Grouped by what you want to do.** Design sources are split into interface design direction, interface review and polish, and design systems and components; a new creative visuals and 3D group is added, and diagrams now include slides. The catalog has 37 projects, 60 Skills and 14 categories.
- **Ten more reviewed sources:** Interface Design, Refactoring UI, Hue, Google Stitch design skills, shadcn/ui, LottieFiles Motion Design, GSAP's official skills (replacing the library card), Shader Dev, Three.js Scroll Worlds and Frontend Slides, plus Better Typography. Each is pinned with licence evidence; recommendations still do not install anything.

## Sessions and Projects

- **Hand a long conversation to a fresh Session.** Conversations past 50 MiB, or idle for 24 hours, offer a handoff in the attention panel; Prepare handoff works while the assistant is busy, and dismissal is remembered for that conversation.
- **A finished task's card says what it left** for the Session and opens to list it.
- **Projects can create a folder** after path confirmation, with durable request receipts. Project settings keep their four navigation choices readable, and default creatures no longer count as a completed Project icon.
- **Credential-named files are never previewed** from the Project tree.
- **Stale Board decisions can be dismissed** without choosing an option. A Session names its Board item's Project by directory, and agents can verify a Project's Links and file a proposal from the CLI.
- **CodeGraph** skips Git-ignored files, so a large ignored tree no longer blocks indexing, and SessionInfo says when a Project has no index to use.

## Gemini and Antigravity

- A Gemini Session interrupted by a daemon restart continues by itself; continuations take turns with other opens, and a turn whose reply already ended is not woken again. A turn the runtime never answers now ends after three silent minutes instead of fifteen.
- Antigravity Sessions support message parsing, handoff execution and cross-machine remote tasks.

English and Taiwan Traditional Chinese contain the current primary product copy; other shipped languages fall back to English for newer text, including the new Skill names. This is a minor release because it adds user-facing capabilities. Store changes are additive; the updater, installer, service-registration code and signed-release identity are unchanged from v2.14.0.
