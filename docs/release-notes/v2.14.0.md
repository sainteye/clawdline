# Clawdline v2.14.0

This release adds local CodeGraph navigation, Project development-service management, an Ops page, and more complete Gemini and terminal workflows. It contains the application changes in the previously tested dev build `ea4eb380112b40764b03c7f1f285322b7e1311e2`.

## Code navigation

- **CodeGraph replaces the active Graphify integration.** The optional, explicitly enabled local service owns its indexes, watches source changes and reconciles their content. Queries refuse missing, busy, stale or unverified results and fall back to current source search. The source scope includes supported extensions, special filenames and validated custom mappings. Existing Graphify files are preserved; historical consent and workflow receipts do not enable CodeGraph.
- **One guidance entry in SessionInfo.** An existing conversation can opt into CodeGraph without editing its draft. Pending guidance accompanies the next ordinary message once; the daemon remembers the native conversation across browsers and restarts, and avoids repeating guidance already included at launch. Slash commands and empty submissions do not consume it. Unknown delivery outcomes are not retried automatically; the same entry offers explicit re-provision after context is cleared. Turning the preference off sends one update, without retracting earlier context or revoking tool permissions.
- **A current, bounded project graph.** The Session and Project viewers use stable symbol identities, source folders and a limited overview. They show source-check and watching status. Graph edges remain navigation evidence and require independent source verification; neither an index nor a guidance receipt proves model use.

## Projects and Ops

- **Manage a Project's development services.** Project setup and SessionInfo can offer to start an existing dev stack or help set one up. Configuration and project links can be inspected without starting services, and the supported reads work through Clawdline Cloud.
- **Project Ops documents in the console and Cloud.** The Ops page lists, creates, renames and resolves Project documents, remembers its selected Project, shows new Agent answers without reloading, and explains blocked resolve requests. Playbooks can refer to these documents. Status changes are announced and long link names wrap.
- **Cancel a Board step explicitly.** A cancelled step records its reason separately from completion. It no longer blocks closing its item, and can be restored while the item is still active.

## Gemini and terminal reliability

- **Gemini uses the selected workflow context.** Owned ACP and native launches retain their original workflow, CodeGraph choice and step-explanation preference; SessionInfo includes project links and dev-stack actions. Protocol-owned Gemini Sessions have the native terminal panel and slash-command path, and relayed messages use the shared Session message cards.
- **Long Gemini tools stay alive while they make progress.** The inactivity watchdog observes tool updates, avoids stale timeout and end-of-turn races, and converges when a worker is stopped. Image cards settle when their original input is dropped.
- **Recover a terminal connection without stopping its shell.** A disconnected terminal offers a fresh connection to the original running shell. Connection-management actions identify only the selected connection and can free capacity independently of shell lifetime. Native terminal Sessions retain their Codex conversation association and recover after a late start observation.
- **Clearer background work and faster inventory reads.** Sessions name pending callbacks instead of appearing idle. Inventory avoids repeated archived-delivery history checks, and an earlier quota request no longer hides a newer Claude Code quota answer.

## Privacy, review and media

- **Secret Handoff receipts no longer fingerprint the value.** New operation receipts exclude secret bytes, length, hashes and keyed fingerprints. This does not erase historical receipts or backups. Operators who used the older implementation should follow the historical-data guidance in [Secret Handoff](../secret-handoff.md); an ordinary update does not purge that data.
- **Cross-surface review keeps one checker and an explicit integration pass.** The starter review Playbook and checker role inspect callers, producers, consumers and omitted surfaces, and preserve unresolved author-intent questions instead of treating them as confirmed defects. Experiment records retain their source-only and role-drift limits; they are not a runtime safety guarantee.
- **Requested videos can be shared as original MP4 links.** The Agent workflow supports the original video instead of forcing it into a GIF, including the documented temporary external-hosting path. The privacy and playback boundaries remain in [video delivery](../video-artifacts.md). Full-width punctuation no longer consumes the start of a sentence after a bare link.
- **Dev signing does not wait on Apple's timestamp service.** Only non-hardened dev signatures use `--timestamp=none`. Official releases retain Developer ID signing, hardened runtime, secure timestamps and notarization.

English and Taiwan Traditional Chinese contain the current primary product copy; other shipped languages retain English fallback for newer text. This is a minor release because it adds user-facing capabilities. CodeGraph preferences add conversation metadata; the updater, installer, service-registration code and signed-release identity are unchanged from v2.13.0. Existing frozen workflow snapshots, tool permissions and user-owned files remain separate from current settings.
