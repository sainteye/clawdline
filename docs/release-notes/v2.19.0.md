# Clawdline v2.19.0

This release adds a voice copilot that you can call about your Sessions, lets agents use Chrome through Clawdline while you watch and take over from a phone, and lets a browser with no account join one machine by invitation. It contains the application changes on `main` at `a86df69eb` on top of v2.18.0.

## Voice copilot

- **Call a voice copilot about your Sessions.** The call button in the Session list toolbar, a hold on a Session's title icon, or a double press on its microphone opens a realtime call that reads Sessions, explains what each is doing in everyday sentences and tells what happened since its last report. It needs an OpenAI API key, kept on the machine in Settings; without one it offers a demo film of a call.
- **It acts only where the machine confirms.** It asks once before sending a message, writes only to the Session under discussion, can start a Session in a Project, answer a waiting question, run Snippets and Playbooks, open or close a Session and smart-name Sessions whose names no longer fit. Each confirmed action is shown and chimes; a claimed action the machine never did is said so.
- **It follows the Session on screen**, on the local console and on Cloud, and on *All machines* reads and acts on each machine's Sessions at their own machine. The call shrinks to a bubble over every page, remembers earlier calls, and shows what the call costs.
- **It speaks, briefs and recaps in the console's language.** The machine's prepared briefing and a Session's recap follow the console, as the call does, and the call's tool log reads in English unless the console is in Taiwan Traditional Chinese.
- **Settings › Voice copilot** chooses its voice, which can be heard first, and short answers; during a call it can be told to speak slower or faster, shorter or longer. It speaks in the console's language, and hanging up ends the call's open voice work.

## Chrome

- **An agent can open, read, click and type in Chrome through Clawdline**, in its own window of Clawdline's dedicated Chromium (`clawdline browser launch`) or a configured Chrome, chosen by an ordered preference with an explicit per-Session choice.
- **You can watch a Session's Chrome tab, take it over and type**, in the console or on a phone through Clawdline Cloud. The panel shows the address, a picture you can zoom and pan, the agent's recent actions, and a phone or desktop layout. A Secret Handoff can be typed into a page.
- **Phone input is dependable.** A tap on a pictured field focuses it even when the tab is zoomed or the view is scaled, and keeps the footer editor and keyboard up on iOS. Send text shows *Sending…*, then *✓ Checked* when the field was read back and matches. A field the site changed shows both texts and can be replaced with yours; *Edit this* pulls a field's text into the draft. A Delete key sits beside Send text, and Backspace on an empty draft reaches the page. Password, one-time-code and card fields are never read.
- **The dedicated Chromium keeps painting while the display sleeps**, so the phone's picture no longer turns black.
- **A Session keeps its Chrome tab across a daemon restart**, and setup preserves consent and close results across service restarts.

## Dictation

- **Dictation can be punctuated by a small model** that keeps the speaker's script, with an editable vocabulary, also from a phone. While recording, the microphone becomes a send button; a dictation sent with the paper plane carries pictures already in the box.

## Machines and access

- **A machine can invite a browser with no account** and admit it until a chosen time. The browser types a short invitation code and uses that one machine; the daemon and browser agree on a key from that code.
- **Both consoles' Devices pages** pair a browser and list devices the same way, follow the header's machine, and say why a list is hidden.

## Grok and Gemini

- **Grok Sessions accept pictures** as native image blocks; pictures too large for one prompt are refused at once without failing the queue, and a picture a Grok Session sends is shown under its next reply.
- **An expired Grok sign-in is renewed or explained** in the quota bar instead of hiding Grok. A Grok turn stopped by a daemon restart says so and settles its tools.
- **Gemini (Antigravity) Sessions** start with the configured default model, switch without transient busy errors, and show as working while background tasks or tools run.

## Phone and Sessions

- Phone header buttons open every option in a vertical menu of labeled rows, and the Session list stays the first sidebar entry.
- The iOS app's web view signs in where it is.
- A built-in Playbook has a Root drive its Board steps to done from a working version.
- An untitled milestone handoff's receiver is named after the work it continues.
- A suggested reply's note context is written in the console's language.

English and Taiwan Traditional Chinese contain the current primary product copy; other shipped languages fall back to English for newer text. This is a minor release because it adds features and settings. The store gains one additive table for the voice copilot's workspace. The updater, installer, service-registration code, supervisor and signed-release identity are unchanged from v2.18.0. The dedicated Chromium now starts with `--disable-backgrounding-occluded-windows`, `--disable-renderer-backgrounding` and `--disable-background-timer-throttling`, and its browser extension has a new payload identity, so an already running dedicated Chromium must be restarted to load it.
