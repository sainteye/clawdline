# Clawdline v2.13.0

This release lets a new Session start on a chosen model, reads Claude's plan quota even when no status line writes it, and gives an unread question a moment before a Session switches to Terminal.

- **Choose the model when starting a Session.** After picking Claude or Codex in the new-Session sheet, a model row offers the same catalog the board uses. Leaving it unset keeps each assistant's default. The row is hidden for Clawdfather, for a start on another fleet machine, for resume, Terminal mode and write-off, and for any daemon older than API level 40, so a hosted console never offers a model an older machine would refuse.
- **Claude's 5h and 7d quota without a status line.** When Claude Code's status line has written no fresh window, Clawdline asks the installed Claude Code for its plan usage through its control protocol, in an isolated scratch directory with no Session, transcript or model request, at most once every 15 minutes. Dispatch decisions, Session info, the status-line corner and the quota footer all read that one answer. Doctor and the footer say when the reading came from Claude Code rather than the status line, and why an ask failed.
- **An unread question no longer throws a Session into Terminal.** When Claude Code or Codex shows a question on a captured screen, the Session waits six seconds and shows a countdown notice before switching to Terminal.

English and Taiwan Traditional Chinese include the current product copy. Other shipped languages retain English fallback for newer untranslated text.

This is a minor release: it adds model selection on start and a new quota source. No storage migration is introduced.
