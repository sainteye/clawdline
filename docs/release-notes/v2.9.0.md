# Clawdline 2.9.0

Receive a notification when a Session stops because its selected model is at capacity, and keep image previews clear while inspecting a picture.

- **Notice model capacity stops.** Model-capacity notifications have their own switch in notification settings, enabled by default and independent of question and system-capacity notifications. The first current capacity reading can notify subscribed devices once per stop and opens the affected Session. These notifications share the existing waiting-notification budget; push-service acceptance does not prove delivery to a device.
- **Clear the image preview.** Tap or click the picture or its frame to hide the controls, then repeat to restore them. Tab restores controls and Escape closes the preview. Zoom can shrink to 75% of the initial displayed size; a tall picture that can still scroll vertically keeps that movement rather than switching pictures.
- **Find product and security information.** The English and Taiwan Traditional Chinese READMEs link directly to the official website, group features by workflow, compare agent-tool workflows and illustrate the Cloud content-encryption boundary and its limits.
- **Make terminal checks more reliable.** Private tmux test panes wait for readiness before assertions. This changes test synchronization, not the behavior of existing Sessions.

English and Taiwan Traditional Chinese include the new notification copy. Other supported languages retain the existing English fallback for newer untranslated text.

This is a minor release because model-capacity notifications and their independent preference add a capability. No incompatible storage migration is introduced.
