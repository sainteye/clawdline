# Clawdline v3.0.0

Since v2.19.0, Clawdline has added Session message boards and installable Session views, expanded
the voice copilot, and made day-to-day navigation faster on desktop and phone.

## Session message boards and views

- Open **Session message boards** from the status bar. Give a board a name and purpose, choose
  a live Session as Lead, and follow replies in one place. Leads can pin summaries, transfer
  leadership, or close completed member Sessions. Posts can open the Session that sent them.
- Sessions in the same Project can use `clawdline session-board` to find a board, join it, read
  new posts and contribute. Member Sessions are grouped in the Session list.
- Install Session view plugins from the sidebar and open them from the status bar. The plugin
  manager shows available views and updates, and each view can choose which Sessions it displays.

## Voice copilot

- Choose **GPT-Live** or **Realtime API** for a call. The copilot displays elapsed time and
  estimated cost, follows the Session you open, and ends the call when you say goodbye.
- Ask about a Project, recent replies, decisions or Session message boards. The copilot can use
  prepared Session recaps and consult original replies when answering a follow-up. The call offers
  suggested questions and keeps the current Session in view.

## Sessions, Board and the Mac app

- Open an existing conversation and see the newest messages while earlier history loads.
  Loading older messages preserves the reader's place. Closing a Session on a phone animates
  the return to the list.
- Desktop Board columns adjust to the available width. The Session menu groups less frequent
  operations under **More commands**. Desktop and phone have separate switches for the quota bar.
- The Mac window keeps its controls in a single bar, and the notch opens the Session list.
  Choosing a Session from the notch menu opens its detail. The app also has an updated icon.
- Drop files and folders into the composer to insert their paths. Drop images to attach them.

## First use and Chrome

- First-run guidance takes you through adding a Project and starting its first Session. The
  Mac Cloud tab guides sign-in and pairing, and paired devices with command permission can act
  when the machine connects.
- Connect Chrome from the setup guide, reorder the browsers used for automatic selection, and
  open a Session browser from either desktop or phone. The browser panel supports navigation,
  reload and mobile layout. The dedicated test browser loads its extension from a stable folder
  so a restart picks up prepared updates.
- Starting an already registered Project's Session can continue while unrelated discovery runs.
  The updater now registers a download before announcing it, so callers can wait for it as soon
  as it appears.

English and Taiwan Traditional Chinese include the latest primary interface copy. Other shipped
languages fall back to English for newer text.
