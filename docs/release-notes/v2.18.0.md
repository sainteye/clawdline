# Clawdline v2.18.0

This release lets Grok Sessions start without permission prompts, keeps scheduled Codex runs out of Codex's chat list, says when Codex is spending credits, and makes Gemini and Grok Sessions far more dependable on the phone. It contains the application changes on `main` at `da5aba86c` on top of v2.17.0.

## Grok

- **New Grok Sessions can start without permission prompts.** A new Workflow setting, *Grok full permission*, is off by default. Turned on, a new ordinary Grok Session starts with Grok's always-approve mode, so only deny rules and hooks still stop a call. A running Session keeps the mode it started with.
- **A Grok Session names itself after its first turn**, as a Gemini Session already did, when Auto-name is on.
- **A Grok turn that reads a photo no longer ends with `frame_too_large`.** Image data an agent reads is dropped as the line arrives instead of being stored as base64 text in the Session database.

## Gemini

- **Gemini explains its steps again.** Since the switch to the AGY 1.5 CLI its role, memory, language and step-explanation instructions were not reaching the model; they now travel in the message itself.
- **Turns Gemini starts itself appear in the conversation**: a turn that wakes after a background task finishes, or when Gemini's own timer fires, is shown instead of the Session looking stopped.
- **A Gemini turn running when the daemon restarts continues afterwards** instead of ending as cancelled.
- **The model you picked stays picked after a reload**, reasoning effort is shown and selectable on AGY 1.5, and a disconnected Gemini Session offers a model switch before it reconnects.
- **A Gemini command whose process closed stops showing as running.**

## Codex

- **Scheduled Codex runs leave Codex's chat list.** A Codex schedule can archive each run's conversation in Codex once Clawdline closes its tab; new Codex schedules have it on, existing schedules are unchanged. A conversation still in use is never archived.
- **A Codex Session spending credits after its weekly window says so.** The quota bar marks it with *Credits*, and the info card shows the balance.
- **A Codex answer reaches an open conversation as it lands**, without leaving and coming back, including on a phone that recovered the Session from its list.

## Sessions and the phone

- **A message sent while Grok or Gemini works goes to the machine** instead of waiting in the browser.
- **A message matching Claude's suggested next prompt is sent**, not left typed in the composer, and the phone's *Press Enter* card is not fooled by the faint suggestion of the same words.
- **The Session info sheet** puts the model switch right after the status and the connection state last.

## Board and usage

- **An item full of superseded plans can make room again.** `clawdline item doc-delete` lets the owning Session delete older plan documents; the latest plan, reviews and the completion report are kept.
- **Usage overview counts today**, and project bars are stacked by agent with plain token counts.

English and Taiwan Traditional Chinese contain the current primary product copy; other shipped languages fall back to English for newer text. This is a minor release because it adds user-facing settings. There is no store schema change. The updater, installer, service-registration code, supervisor and signed-release identity are unchanged from v2.17.0; the daemon's stop path now ends Gemini and Grok hosts before the Cloud context.
