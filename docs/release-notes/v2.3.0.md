# Clawdline 2.3.0

An opt-in Gemini preview brings personal-account conversations, native model controls and saved history to the phone and desktop console.

- **Gemini conversations.** The preview uses the official Antigravity CLI's personal-account ACP connection to create a conversation, send a message and read its streaming reply through the existing Session interface. It requires the existing personal preview setup; AI Credits and API-key fallbacks are not enabled.
- **History survives a restart.** Saved Gemini conversations retain their identity and remain readable before the CLI reconnects. A new message resumes the same native conversation. An interrupted prompt is not automatically resent. Older native conversations can be found in the project's history chooser and imported explicitly.
- **Read the whole conversation.** Older structured pages stay in place while the newest reply updates. Repeated text in separate turns remains separate, and completed tools refresh their retained older page without dropping messages when a result grows.
- **Models and reasoning effort are separate.** Gemini Session Info presents the native offered base models and reasoning levels independently. Available native quota readings remain separate from conversation context.
- **Less friction on the phone.** The Gemini preview uses the same gradient mark across entry points, accepts input without a redundant availability preflight, and continues displaying the reply after the delivered message appears.
- **A temporary terminal-listing failure keeps one Session.** A returning terminal is reconciled with its original Session instead of appearing as a duplicate.
- **Phone pairing follows the setup guide.** The pairing QR view shows the same three steps as the guide, with one phone's progress kept together.

Gemini remains an opt-in personal-account preview. This release does not broaden its availability to other accounts or claim that the full Gemini integration is complete.
