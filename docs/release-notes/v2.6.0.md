# Clawdline 2.6.0

Find help in your interface language, ask private questions from Cloud, and read long tool results without loading every detail at once.

- **Find answers and ask private questions.** The Cloud help center offers searchable, paginated FAQs and private question threads in the existing interface language. Questions can include screenshots without a separate title; follow-ups support text, images and readable Markdown replies. The sidebar links directly to your questions and explains who can read them. Administrator tools have their own area, question details identify the requester, and administrators can opt into new-question notifications. Answering Agents use a dedicated support workspace and scoped API access.
- **Read tool output when you need it.** Tool cards show readable result previews and load stored output, long messages and patches when expanded. Images open directly with visible loading feedback and remain available as the transcript window moves. Automatic tool screenshots stay out of cards while explicit image outputs remain visible. Expanded content keeps its identity when older history arrives and uses the conversation's Markdown renderer.
- **Transfer less repeated Cloud content.** Transcript updates carry changed entries, structured reads negotiate compressed encrypted replies, Board lists fetch full card content when opened, and role catalogs reuse a verified display version after reload. These changes preserve the existing permission and representation checks; savings depend on the content being read.
- **Keep unfinished messages with their Session.** Composer drafts are separate for each Session, save when you leave or background the page, and clear when sent or emptied. Phone Session details retain a usable browser Back destination after restoring a direct link.
- **Recover a page without losing the surrounding Session.** A missing page module shows a localized recovery card with a manual reload action. Where a Session shell is available, Back to Sessions keeps it mounted. Recovery does not automatically reload an active editor or promise that a retry will succeed. Cloud builds reject incomplete deployment declarations before producing a hosted bundle.
- **Start and coordinate work with fewer interruptions.** New Board Sessions keep model and role options collapsed initially, team pickers remain open during Project refreshes, and Codex model-capacity failures bring the Session to your attention. Agents can create task webhooks through the command line, and sandboxed scheduled Sessions can hand work to a fresh Session without writing outside their workspace.
- **Use website Settings consistently.** The retired standalone Settings window is removed from the App, setup and localization review links use the supported website flow, the keyboard cheat sheet closes when its button is pressed again, and image previews retain a translucent loading indicator.

English and Taiwan Traditional Chinese include the new product copy. Other supported languages retain the existing English fallback for newer untranslated text.
