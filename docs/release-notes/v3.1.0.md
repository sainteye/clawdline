# Clawdline v3.1.0

Since v3.0.0, Clawdline has added threaded replies to Session message boards, redesigned the
Session view launcher, and improved live dictation and remote Session recovery.

## Session message boards

- Reply directly to a post. Its replies stay in a thread under the original message.
- Open a board on its messages. Members and management are one tap away, and the pinned summary
  has its own space. The toolbar wraps on narrow boards, and each post has more room.

## Session views

- Browse view previews under **Manage views**. Installed views, available updates, and the
  installation review are easier to find.
- On desktop, open a view from a compact launcher or pin it next to the Session list.
  Switch pinned views using their cover previews. Departures fits narrower panes.
- **Lantern Deep** brings Sessions into a drawn cavern with characters, camps, and encounters.
  The scene keeps its place through brief stale readings. View plugins can also show a Session's
  context use, subagents, and background shells.

## Voice and Sessions

- Dictation previews text while you speak. The recording panel switches engines, supports
  Traditional Chinese, and lets you scroll through longer input. Browser dictation can stream
  microphone audio when using the Realtime engine.
- Voice correction has its own setting. Voice reports use the current Sessions and their recaps.
- A new Session in a recent Project can start from a prepared shell. An early message waits for
  the assistant to be ready. New Codex Sessions follow the machine's permission setting.
- Remote Session reads and the verified Session list stay available through brief reconnects and
  incomplete scans. The fleet update notice opens the selected machine, and an eligible InstaBox
  machine still offers its wake control.
- Open Settings or hide Clawdline from the notch menu. Schedule history again shows its webhook
  controls.

## Bots

For installations with Bots enabled, the roster now recovers from partial source availability,
and the tower shows unread replies and names with its controls folded. Bot chats support picture
drops across the chat area, full-size image previews, editing queued messages, and a clearer
recovery card for messages with unconfirmed delivery. A draft stays editable when a send never
left the browser. An earlier uncertain message can be checked or removed independently.

Bot settings show agent models, skills, and Agent choices where the source supports them.
Personal workspace Bots can join groups, mention one another, and hand work to a Bot in another
Project. The lead setup, artifacts, routines, and phone controls also received improvements.
Sessions dispatched by a Bot open Claude Code in Auto mode.
