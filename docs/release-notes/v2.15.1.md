# Clawdline v2.15.1

This patch release contains the application changes in the previously tested dev build `c66417948` on top of v2.15.0.

## Fixes

- **Gemini CLI 1.5.0 is recognised.** That version prints its `--help` text to stderr instead of stdout, so the new-Session sheet reported the installed CLI as unsupported although it has every option Clawdline needs. The help probe now reads both streams under the same 64 KiB bound; the version probe still reads stdout only.

## Documentation

- Installation references and the release acceptance record follow the published v2.15.0 release.

This is a patch release because it only fixes existing behaviour. Store changes: none. The updater, installer, service-registration code and signed-release identity are unchanged from v2.15.0.
