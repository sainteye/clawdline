# Clawdline 2.5.0

Watch published videos inside the conversation, follow the subagents working for your assistants, and manage more of your work without leaving Clawdline.

- **Watch videos in place.** Published MP4 links open a dedicated lightbox above the conversation. Playback starts while encrypted chunks arrive, with native playback controls, a reserved player area, loading feedback and reliable closing and reopening. Conversation cards select detailed preview frames from several parts of the movie. Links to another Session on the same paired machine use that video's source identity while preserving the conversation underneath.
- **Follow subagents from Cloud.** Session lists show current provider subagent counts. Open their activity views to see their own model and work; viewing the activity clears its phone indicator. Claude Code and Codex subagents retain their provider identities.
- **Use a wider Board on desktop.** Desktop columns fit the console and scroll horizontally while the phone layout stays familiar. Assignments follow the Agent language preference.
- **Keep moving while actions finish.** Common actions show their pending state, and Playbook starts show loading feedback. Console shortcuts have a discoverable cheat sheet. Phone terminal pasting opens its input before waiting for clipboard access, and scheduled history keeps its Close button available while scrolling.
- **Let Agents maintain Playbooks and leave Notes.** The command line can list, create, edit and delete saved Playbooks through the daemon's credential gate. Live Clawdline children can leave attention Notes for the person. Playbook keeps its English product name in the Traditional Chinese console.
- **Keep assistant conversations connected.** Managed Codex sends preserve their conversation history. Assistants started in Terminal can receive Session messages. Codex children with edit permission can stage and commit their changes and start with configurations containing a retired Codex setting. Gemini supports naming from its saved conversation, interrupting a turn, queuing the next message and answering native permission offers without cancelling the conversation.
- **Recover without unnecessary interruptions.** Sends can retry after execution verification recovers. Returning to the app rechecks a retained sign-in screen; temporary startup connection failures do not immediately become a sign-in request. Restart recovery offers can be dismissed from the Session list. Larger image messages pass Cloud envelope validation.
- **Review an update before installing.** The update flow shows the release changelog before confirmation. Session counts prioritize work needing your attention, All machines hides verified Dev builds ahead of the public release, and Cloud home-screen launches use the logo splash screen.

This release also makes screen capture, native role startup, quota and encrypted-carrier regression checks wait for their actual completion boundaries.
