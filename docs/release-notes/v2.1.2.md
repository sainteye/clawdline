# Clawdline 2.1.2

Cloud reads recover more reliably, and an interrupted refresh no longer covers your work with a pairing prompt.

- Existing paired browsers can keep reading over a direct connection without pairing again.
- A direct read refused by an older machine automatically tries the authenticated relay within the same timeout.
- Slow reads no longer make other reads wait behind one shared operation lock.
- A refresh that still fails appears in a small, dismissible status row. Your content and unsent drafts stay available, and a successful refresh clears the notice.
