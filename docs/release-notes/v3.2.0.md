# Clawdline v3.2.0

Clawdline v3.2.0 makes Bots easier to find, manage, and connect to other tools.
It also improves voice calls, Session task summaries, and message boards.

## Bots

- The roster puts unread conversations above the regular list. You can group
  Bots by machine, see when they were last active, and keep names and status in
  view in the tower while Bots work.
- Settings report when a change saves, even with other activity in flight.
  Long setup lists leave the removal control accessible. Chat explains saved
  settings, new conversations, and routine progress.
- Create and edit approval cards stay in the conversation. Cards show the
  destination Project, including on older consoles, and the Lead can edit Bots
  in other Projects on the same machine.
- Open Markdown attachments in Bot chats and the library. Reports from Sessions
  appear as sources, and dispatched Sessions show the task and the Bot that
  assigned it. Follow-ups can continue past ten minutes. Claude Code dispatch
  opens the composer, and Claude Code and Codex Bots can start on Linux.
- Owners can find webhook setup and public addresses in settings. Bots can
  retrieve their setup guide, configure a webhook in chat, and report its
  address. Main-branch CI failures can wake a Bot through an authenticated
  routine webhook.
- Cloud records which roster read failed, improving diagnosis when a Bot source
  is unavailable.

## Sessions and voice

- Session task rows are more compact, and child Session reports break results
  into readable sections.
- The voice assistant can end a call and report fixes and features from the
  Session's GitHub repository. Codex rate-limit choices appear in the
  conversation.
- A Lead who is the last member of a message board can leave and archive it.
