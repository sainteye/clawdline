# Clawdline v2.16.0

This release adds Grok coding Sessions, lets Sessions coordinate when no Clawdfather is online, and fixes Session naming, Gemini closing, voice input and signed-out guidance. It contains the application changes in the previously tested dev build `513bfeeff` on top of v2.15.1.

## Grok coding Sessions

- **Open a Grok Session.** Clawdline recognises the official Grok Build coding CLI by its fingerprint and starts an owned provider host without sending a model prompt. Session, history, permission, Board assignment, callback and dispatch keep the actual provider and its native conversation. Supervised and full-access launches replace native permission defaults; edits-only access and unverified effort levels are refused rather than approximated.
- **Session information and account quota.** SessionInfo and the quota footer show Grok's own account quota and failure names. Without a verified provider reading the quota stays unknown instead of borrowing a Gemini label or showing zero.
- **Grok's official mark** is used across quota and Session controls.
- **Turns end on Grok's own evidence.** A turn succeeds only on Grok's native completion; cancelled tools stay marked cancelled with their partial output; unsupported pictures are refused before storage or model input.
- **Replies stay in their own exchange.** Idle replies and unrelated string-ID replies are discarded before they can block or enter the next request.

## Sessions

- **Sessions coordinate without an online Clawdfather.** When the role holder is proven offline its projection is released; live Roots can request cooperative pauses, and wake and retry stay scoped to the requester or current coordinator.
- **Renamed Sessions show their new name immediately**, on desktop and phone, instead of briefly reverting to an older in-flight answer.
- **Signed-out assistants explain how to sign in.** When an installed assistant reports it is not logged in, the start sheet names it and shows its login command, in English and Taiwan Traditional Chinese.
- **Gemini conversations stay closed** when stopped during restore or a quota read; reopened history rows can read public CLI quota again.
- **Voice input keeps the recording** when the browser's completion stalls, and a retained recording can be retried without opening the microphone again.
- **Codex history** keeps valid replies within its request budget.

## Performance

- Update checks download the release manifest and its signatures together. Inventory keeps restored work visible without repeating historical Git reads.

English and Taiwan Traditional Chinese contain the current primary product copy; other shipped languages fall back to English for newer text. This is a minor release because it adds user-facing capabilities. Store changes: none. The updater now reads the manifest and its signature file concurrently (bounded to two reads); the installer, service-registration code, supervisor and signed-release identity are unchanged from v2.15.1.
