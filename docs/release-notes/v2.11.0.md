# Clawdline v2.11.0

This release makes the Terminal panel the one place to see and operate a Session's own CLI, adds a library of saved Skills and tools a Session can prepare, and makes native commands easier to take over.

- **Terminal is the one terminal view.** The Session menu no longer repeats a read-only Live screen where the interactive Terminal exists; Open a terminal moves under More commands. Terminal now draws the CLI in colour on tmux, from the same capture whose plain text guards each keystroke. Gemini's standalone CLI gets the Terminal too. Live screen remains for Sessions the Terminal does not serve.
- **Answering a prompt in Terminal is no longer refused by a ticking clock.** A permission prompt under a running tool refused every Enter with `input_moved`, because elapsed times, token counters, spinners and a blinking bullet changed the screen every second. Those no longer count as a change; a different question or dialog still refuses the key.
- **Take over native commands without losing a draft.** Slash commands that Claude Code or Codex answer in their own interface continue in Terminal, confirmed deliveries settle after a verified frame, and uncertain outcomes are kept rather than replayed. `/cost` no longer waits forever when Claude records it as `/usage`.
- **Prepare saved Skills and tools.** A machine-private tool library offers reviewed projects and pinned Skills in bilingual categories, including four web animation libraries. Preparing one attaches its setup instructions to the composer for the exact Session; nothing is installed by the daemon. The library opens on useful projects and uses larger text.
- **Gemini quota and naming.** On phones the compact quota bar shows Gemini's all-models 7-day window, and automatic naming uses the Session's own assistant and model.
- **Video previews and account quotas keep their layout** after a movie is opened.
- **Groundwork for Board issue sync.** The rules for mirroring a Board item to one GitHub or Jira issue, and connecting this machine's GitHub account with a device code, are in place; the Board does not offer the option yet.

Cloud administrators also get a public page visit overview in the hosted console.

English and Taiwan Traditional Chinese include the current product copy. Other shipped languages retain English fallback for newer untranslated text.

This is a minor release because the tool library and Gemini Terminal add capabilities. No incompatible storage migration is introduced. The native terminal frame gains an optional `styled` field; older consoles ignore it and newer consoles fall back to plain text from older daemons.
