The first release of Clawdline as it is today: one daemon (Go) that serves the console, on macOS
and Linux, installed with one command and updated in place.

## Install

```sh
curl -fsSL https://raw.githubusercontent.com/sainteye/clawdline/main/install.sh | sh
```

It runs as a per-user service that starts at login (a LaunchAgent on macOS, a `systemd --user`
unit on Linux), needs no `sudo`, Go or Node.js, and opens the console when it is done. On a Mac
with a desktop it also installs the menu-bar app (Apple silicon). Add `-s -- --headless` after
`sh` on a server. Every option: [docs/user/install.md](https://github.com/sainteye/clawdline/blob/main/docs/user/install.md).

## Updates

From this release on, a machine checks for new releases by itself. The console's Settings page
and `clawdline update` say when there is one; **立即更新** or `clawdline update --apply` installs
it. Every release is checked against its Ed25519-signed manifest before anything is replaced, the
database is snapshotted, and a release that does not come up healthy within a minute is rolled
back with its reason shown. Automatic installation is off until you turn it on per machine, and
it never restarts while a session the daemon started is busy.
[docs/updates.md](https://github.com/sainteye/clawdline/blob/main/docs/updates.md)

A newer console talking to an older machine now says that machine needs an update, feature by
feature, instead of showing a read failure.

## Coming from earlier versions

- **v0.8.0 and older** were the macOS-only Swift app, now retired. This release does not read or
  change its state; install as above.
- **A source checkout** (`clawdline serve` or `tools/deploy-linux-user.sh`) keeps working as
  before. On Linux, `clawdline setup --adopt` moves such a machine onto releases.

## Assets

`clawdline_v0.10.0_<os>_<arch>.tar.gz` holds the daemon and its console for macOS and Linux on
arm64 and amd64; `Clawdline-v0.10.0-macos-arm64.tar.gz` the app. `manifest.json` and
`manifest.sig.json` are what the installer and the updater verify; `SHA256SUMS` is for checking by
hand.
