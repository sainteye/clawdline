# Clawdline v2.12.0

This release connects Board work to GitHub and Jira, exposes Gemini's protocol state, and makes file drops and refused-message recovery easier to use.

- **Sync Board items with GitHub or Jira.** Choose a tracker on the Board and connect it from Settings, including on a phone. A synced item opens its linked issue when work starts and closes it when work finishes. The authorization flow scrolls into view, and the Jira connection links directly to Atlassian's API token page.
- **See Gemini's reported protocol state.** Owned Gemini Sessions show the state received from ACP, while bounded private lifecycle evidence helps diagnose a turn. Protocol evidence does not guess that a turn has completed.
- **Retry after a terminal recovers.** A message refused because the terminal could not be read can be retried after recovery; an earlier Cloud refusal receipt no longer blocks the new attempt.
- **Name folders outside Git correctly.** Project sync recognizes a folder without a repository even when Git adds a filesystem-boundary explanation, rather than reporting the folder as unreadable.
- **Drop file and folder references into a draft.** Non-image files and folders insert their paths. Images continue to arrive as attachments, including when dropped through the macOS app.
- **Prepare Harness² from the tool library.** Its reviewed entry includes setup guidance and research context; preparing it attaches instructions rather than installing or running an experiment.
- **Read public traffic by the hour.** Cloud administrators get four hourly line charts with today selected by default, replacing the previous summary cards.
- **Recognize the macOS background service.** The managed service now runs as `clawdline-daemon`; the public command remains `clawdline`. Signed macOS archives and the App carry the separately named service. After updating, macOS may ask for an existing file permission again under the new service identity. Folder consent remains separate from an assistant's sandbox permissions; the troubleshooting guide explains the distinction.

English and Taiwan Traditional Chinese include the current product copy. Other shipped languages retain English fallback for newer untranslated text.

This is a minor release because Board issue sync and the new protocol visibility add capabilities. No incompatible storage migration is introduced. The updater preserves its health check and rollback path while selecting the new macOS service name.
