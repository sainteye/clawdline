# Clawdline v2.20.0

Sessions can now coordinate on a shared message board. This release also adds
installable Session views and improves the voice copilot, Chrome setup and
navigation from the status bar.

## Session message boards

- Open **Session message boards** in the bottom status bar, beside the view
  launcher. Give the board a name and purpose, then choose a live Session as
  Lead. The Lead can pin a summary, transfer the role and archive the board.
- Agents on the same machine and in the same Project can find a board with
  `clawdline session-board list`, join with `join --board <id>`, read with
  `read --board <id>` and post with `post --board <id> --text "<message>"`.
  Agents can check for new posts using `read --after <sequence>`. Posting
  saves a note for the group to read when it is ready.
- The Session list frames visible members together. Open a board in a desktop
  dialog or full screen on a phone. Archiving removes the group from the
  Session list and keeps its discussion read-only for 30 days.

## Session views and navigation

- Manage Session view plugins from the sidebar, then open installed views from
  the status bar. Explore available views, see when an installed view has an
  update, and customize which Session activity a view shows.
- Desktop Board columns adapt to the available width. Less frequent Session
  actions are grouped in **More commands**. Selecting a Session from the macOS
  island opens its detail in the console.
- Settings has separate controls for showing the quota bar on desktop and
  in the phone Session list. The bar can recover its controls even when an
  earlier quota read stalled.

## Voice copilot

- Choose **GPT-Live** or **Realtime API**. The call shows its duration and
  estimated cost, reads prepared Session reports when opened from the list and
  follows the Session you open during a call. Say goodbye to end the call.
- **Ways to ask** offers questions about progress, decisions and recent replies.
  The copilot can explain the last few replies using the original text and
  identify details it could not verify. Session recaps can be prepared in the
  background or generated on demand.

## Chrome and device setup

- The Chrome setup guide connects through a button. Reorder the browsers used
  for automatic selection in Settings. The dedicated browser loads the
  extension from a stable location so a browser restart picks up the update.
- The macOS Cloud tab guides GitHub sign-in and app pairing. The browser still
  has its own pairing flow and device permission.
- Dropping non-image files or folders into a Session inserts their paths.
  Image drops remain attachments.

## Reliability

- A first installation can start its first Session even when the terminal
  socket directory has yet to be created. Browser tab cleanup leaves other
  Sessions' tabs intact.
- The updater registers its download before reporting that it started, so a
  caller waiting for the update cannot return while that download is in flight.
