# Clawdline v2.12.1

This release makes assisted browser pairing finish on its own, makes updates recover the background service when macOS fails to reload it, and simplifies the quota footer.

- **Assisted pairing finishes without a last click.** When the helper's observed fingerprints match the authenticated handover for the exact offer and machine, the pairing dialog closes by itself, whichever arrives first. Missing, mismatched or late evidence still falls back to comparing fingerprints by hand.
- **Updates restore the background service before claiming a rollback.** A transient `launchctl bootstrap` failure is retried within the existing service-command deadline. A rollback re-registers an unloaded job, including when both releases use the named `clawdline-daemon` service, and keeps recovery pending until the previous console answers. Exhausted recovery is reported as a failure rather than as `rolled_back`. This protects updates *from* v2.12.1 onward; an installed v2.12.0 updater keeps its published behavior.
- **The quota footer shows each provider's 7-day window.** Desktop and phone show one reading per provider: the all-models 7d window, or the tightest window when a provider has none. Clicking a provider still opens every window in its detail dialog.

English and Taiwan Traditional Chinese include the current product copy. Other shipped languages retain English fallback for newer untranslated text.

This is a patch release: it refines existing pairing, update and quota behavior without adding a new capability. No storage migration is introduced.
