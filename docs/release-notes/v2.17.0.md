# Clawdline v2.17.0

This release lets a Session take your next to-do once its own work is done, folds finished tool output, shows what a Codex approval is asking on the phone, and fixes two things that stopped Agents. It contains the application changes on `main` at `5f5f8ec79` on top of v2.16.0.

## To-dos

- **A Session can take your next to-do when it finishes.** A new Workflow setting, *Take to-dos when a Session finishes*, is off by default, and off behaves exactly as before: your to-dos wait until you press Send. Turned on, a root Session whose own work is done and verified, and that is not waiting for your answer, takes your oldest unsent to-do at the end of its turn (`clawdline todo take`) and does it in the same turn. Nothing is typed into its terminal; one to-do is taken at a time, oldest first, and the row shows *Taken by Session*. Rows the Session wrote itself and child Sessions are not affected. A Session that is already idle takes the next to-do after you next talk to it. The setting can be changed from a phone through Clawdline Cloud.

## Sessions

- **Codex approvals say what they ask.** On a phone, a Codex tool approval or command approval now shows its question — the tool request and its parameters, or the command — above the choices, and each choice shows its name and description separately instead of one run-together label.
- **Finished tool output is folded.** A completed tool call keeps its name, status and duration, and its output waits behind one *Output* row. A failed or cancelled call stays open so its error is visible.
- **New Sessions can publish output files again.** When the session output store reached its store-wide limit it refused every new conversation; it now lets the least recently used conversation index go instead.

## Agents

- **Agents are no longer told to read capacity they cannot read.** The capacity reference told an Agent to read the machine's live capacity before acting and stop without a reading, but that route only accepts a paired device. An Agent setting up a schedule stopped there. The reference now tells it to send the request and handle the typed refusal.

English and Taiwan Traditional Chinese contain the current primary product copy; other shipped languages fall back to English for newer text. This is a minor release because it adds a user-facing setting. Store changes: `session_direct_todos` gains a nullable `taken_at` column, added in place on first start; existing rows are unchanged. The updater, installer, service-registration code, supervisor and signed-release identity are unchanged from v2.16.0.
