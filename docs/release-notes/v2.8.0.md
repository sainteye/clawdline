# Clawdline 2.8.0

Inspect missing quota readings and prepare a private support report from Doctor.

- **Check the affected machine.** Open Settings → Status → Doctor to inspect the running Clawdline version, recognized Claude Code and Codex CLI versions, current quota readings and recent recorded quota transitions. `clawdline doctor --json` reads the same authenticated report from the running daemon. Missing readings remain unknown, and a real zero is preserved.
- **Review before sharing.** Preview or download the report without uploading it. Doctor uses fixed CLI version checks and existing quota evidence; it sends no model prompt, reads no sign-in credential and introduces no provider polling or automatic upload. The exported report excludes account identifiers, private paths and conversation content.
- **Submit a private report deliberately.** Signed-in Cloud members can explicitly submit a reviewed report, optional screenshots and a problem description to private support. If the affected machine is unavailable, import a previously downloaded report at the Cloud Doctor page. Submission requires consent; an uncertain result can be checked again with the same report and request key, including after reload.
- **Keep diagnostic limits visible.** Recent history records quota changes observed when Clawdline reads quota data, with retention and storage gaps reported. A report does not establish upstream authentication status, observe a provider's usage request or prove the cause of an earlier incident.

English and Taiwan Traditional Chinese include the new product copy. Other supported languages retain the existing English fallback for newer untranslated text.
