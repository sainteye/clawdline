# Clawdline v2.10.0

This release adds optional Session workflows, an interactive project graph, a shared entrance for generated files, and more complete Gemini Session controls.

- **Choose a workflow for new Sessions.** Machine settings offer the standard workflow, Poteto, or an evidence-led workflow. Each Session retains the workflow and launch instructions it started with. Graphify guidance is an independent option; headers show an optional workflow only when it is confirmed.
- **Explore a project's graph.** Projects and Session information can open an interactive Sigma graph from an optional local Graphify index, including through pinned Cloud Sessions. A missing index can be built locally with visible build stages. Index availability and freshness are checked before use; a graph is navigation evidence rather than proof of a code relationship.
- **Find and share generated files.** Sessions expose recorded output files from one entrance on the local console and Cloud. Pictures use the existing preview controls, shared links retain the selected file across navigation, and returning to the file list keeps closed previews closed. The entrance appears after an output is recorded.
- **Use more of Gemini from Clawdline.** Gemini Sessions display native pictures and compact, readable tool activity, support automatic titles with the Session model, and offer archiving, skill menus, Board assignments, and Stop current work. Provider plan eligibility and native quota windows include Argon's separate weekly bucket.
- **Pair a browser with clearer guidance.** Remote settings in both app tabs expose pairing. Setup first suggests an existing helper machine and lets the person choose Claude or Codex. Returning Cloud viewers restore saved pairings before opening Sessions.
- **Keep machine counts and delivery evidence accurate.** Machine pickers count Sessions from the complete status inventory. Large delivery receipts keep full evidence alongside their short summaries. Native notice tests wait for their asynchronous dead-letter effect before cleanup.
- **Use the connected Clawdline mark throughout the app.** Application assets, browser icons and navigation share the terminal-line mark. Large illustrations add a subtle pixel grid and left-to-right light flow.

English and Taiwan Traditional Chinese include the current product copy. Other shipped languages retain English fallback for newer untranslated text.

This is a minor release because workflows, project graphs and output-file navigation add capabilities. No incompatible storage migration is introduced. Existing integration consent remains required; optional workflows and Graphify do not grant additional permissions.
