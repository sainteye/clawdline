# Clawdline 2.2.0

A setup guide in the Mac app walks you through connecting Cloud and pairing your browser and phone, and Cloud reads hold up better when several devices are open.

- **Setup guide.** A button beside the connection light in the Mac app counts what is set up: the Mac app, a browser and a phone. It opens a guide that signs this machine in, connects it, and pairs each device in turn. Any step can be skipped, and the finished screen takes you back to it. Choosing **Keep it local** leaves a quiet **Local** mark instead. Open it again from **Help → Setup Guide…**.
- **Pairing from a QR or link finishes at once.** After you scan the machine's QR or open its pairing link, there is no fingerprint screen to compare; the pairing is already verified.
- **Scan to pair.** If a machine you can see online stops answering a device, for example after you removed that device on the machine, the notice offers **Scan to pair** instead of only **Try again**.
- **Fewer false alarms.** A read that fails for a moment, such as while the machine restarts or your phone wakes, no longer flashes a failure notice.
- **Reads wait instead of failing.** When several devices read the same machine at once, extra reads now wait their turn instead of being refused.
- Image drop frames stay visible over Session banners.
- A Secret Handoff Note finishes as soon as you submit the value.
