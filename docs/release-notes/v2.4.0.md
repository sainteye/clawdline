# Clawdline 2.4.0

Gemini gains roles, shared Project memory and native workers, and its Session entry is available to everyone connected to a configured machine.

- **Gemini for connected users.** The ordinary Session chooser no longer hides Gemini behind administrator access. The machine owner still enables the personal-account integration and signs into the official Antigravity CLI with AI Credits off.
- **Separate conversations in one Project.** Two Gemini conversations can remain active in the same Project without sharing their messages or permission answers. Identical permission questions in different Sessions remain separate requests.
- **Answer native tool permissions.** The phone and desktop Session display the CLI's offered choices and return the selected answer to that request. A workspace refusal remains a refusal, rather than an approval prompt that cannot succeed.
- **Keep the original role and memory.** A Gemini conversation starts with its selected role, handbook, enabled skills, shared Project memory and language. Resuming preserves that original snapshot. Native tools identify their own Clawdline conversation instead of borrowing a parent assistant's identity.
- **Gemini workers use the existing workflow.** CLI dispatch can run a Gemini child through the existing role squad, claimed worktree, acceptance and result lifecycle. Native model and permission settings require acknowledgements. Closing a worker stops its exact process while retaining saved history.
- **Completion notices keep their own receipts.** A Gemini root can receive a worker's completion notice and acknowledge the task through Clawdline. A cancelled or limited turn is not counted as a completed observation, and an unrelated later success cannot mark that earlier notice read.
- **Cloud terminals accept the current content key.** Session and terminal access now use the same current-key and viewer-grant rules, fixing terminal entries that were refused while the corresponding Session remained readable.
- **Connection delays keep the pairing.** A delayed Cloud read no longer asks the person to pair the machine again. A confirmed pairing failure still receives its own recovery guidance.
- **See the next scheduled agent.** Schedule details show the agent assigned to the next run.

Gemini remains a machine-enabled personal-account preview using Antigravity's native ACP connection. It does not enable AI Credits, API-key fallbacks or paid APIs. This native process path supports macOS and Linux; native terminal attachment and turn-only cancellation are not provided.
