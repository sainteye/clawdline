# Provider marks

`grok.svg` is the unmodified `Grok_Logomark_Light.svg` from the
[official Grok brand assets](https://data.x.ai/logos/SpaceXAI_Grok_Assets.zip),
linked by the [official brand guidelines](https://x.ai/legal/brand-guidelines).
The white logomark is used on the console's dark surfaces. The shared assistant
renderer supplies the same mark to quota readings, Session identity, launch
choices, transcripts and Board assignment choices. It is served locally.

The mark remains the property of its owner and is used only to identify Grok.
Its use is governed by the linked brand guidelines; the repository license does
not grant rights to the mark.
