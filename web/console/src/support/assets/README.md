# Support staff avatar

`support-human-v1.png` is a 160-pixel RGBA product asset generated with the built-in ImageGen tool
on 2026-10-28, then resized locally. No external image API or API key was used.

Prompt direction: a friendly gender-neutral human support teammate, short dark hair, terracotta
sweater, charcoal headset, warm skin, gentle smile, simple clay illustration, dark circular backdrop
and transparent outer corners. No lettering, purple, robot or photorealistic portrait. Designed to
remain legible at conversation-avatar size. Members retain their verified GitHub avatars; the Agent
retains the separate Clawdline brand mark. This illustration does not identify a real employee.
