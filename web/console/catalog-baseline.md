# Console catalog baseline

`public/catalogs/baseline-keys.json` records the keys present in the first complete nine-language release. Its `version` starts at 1. After that release, add new English and `zh-Hant` copy in the same code change. Other languages may omit those new keys until a catch-up; the validator reports their missing count and runtime fills each gap from English while retaining the selected document language.

The source extraction is reproducible from the repository root with `node web/console/tools/compose-catalogs.mjs` (without `--write`); it prints `{"english":3389,"chinese":3389,"added":909}`. The pinned Projects renderer also needs 10 Project and 54 worktree adapter keys. Thirteen complete numeric sentence templates replace 19 brittle JSX fragments. Four Board modal eyebrows found in the real browser are now translated. The checked-in v1 `baseline-keys.json` therefore has **3,389 keys**, including `lang` and `dir` (3,387 content keys). `catalog-inventory.json` classifies the full count. The checked-in catalogs, not the source-extraction helper, are the release artifacts. Run `node web/console/tools/validate-catalog.mjs --reference web/console/public/catalogs/en.json --target web/console/public/catalogs/<tag>.json --tag <tag> --initial` for each initial-release language.

Before this initial release, a corrected sentence may replace its unused fragment keys in all nine catalogs and in baseline v1 in one change. The 13 count templates above were reviewed with 0, 1 and many values and with a long source label. After the initial release, use the deletion and versioning process below.

When removing a baseline key, remove it from English and every translated catalog in the same change, remove it from `baseline-keys.json`, and increment `version`. A key left in any translated catalog is invalid because runtime rejects keys absent from English. Review the changed key set with the strict nine-language `--initial` validator before releasing that deletion. Do not add new keys to the baseline during routine copy changes; a later explicit rebaseline may add them after every language has been completed and checked.
